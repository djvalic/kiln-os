# Sponsoring Kiln OS

Kiln OS is a project I build in my free time, because I enjoy it and
because I like making things I think are cool. If it is useful to you and
you would like to say thanks, you can sponsor it through
[GitHub Sponsors](https://github.com/sponsors/djvalic). That is
appreciated, and it is always optional.

## What sponsoring means

- **It is a thank-you, not a purchase.** Sponsoring doesn't buy support,
  priority or a say in the roadmap, and it doesn't come with a support
  contract, a response time or a warranty. Kiln OS is provided as is, as
  [LICENSE](../LICENSE) says.
- **Everyone's issues and requests are treated the same.** I decide what
  to work on by what keeps printers safe and stable, how many people a
  change helps, and what I find worth my free time. Whether someone
  sponsors doesn't change the order or the speed.
- **Nothing is held back for sponsors.** Every feature, release and
  document is public, and Kiln OS stays free and open source under the
  GPL.
- **Sponsor tiers, if there are any, are thank-you levels only.**

## Other ways to help

Help that isn't money counts just as much:

- Try the release candidates and say what you find.
- Report bugs with the details that help fix them ([logs.md](logs.md)).
- Send pull requests, translations or plugins
  ([CONTRIBUTING.md](../CONTRIBUTING.md), [plugin-first.md](plugin-first.md)).
- Answer other people's questions in the issues.

Thank you for using Kiln OS.
