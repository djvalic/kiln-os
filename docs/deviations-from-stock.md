# Deviations from stock: quick reference

Everything the open stack does differently from the stock AD5X (software 3.1.0, control 1.1.1),
for when something misbehaves on the real printer. Each entry gives the symptom to look for and how
to go back to stock behaviour. Keep this list current: add an entry whenever a change from stock is
made.

Risk: **High** = could damage hardware or stop a print, **Med** = could stop startup, a swap or a
feature, **Low** = cosmetic or easy to spot.

Interactive root logins get 022 from the stock `/etc/profile.d/umask.sh`. Our `S50dropbear` is an override of the Buildroot script (`board/ad5x/rootfs-overlay/etc/init.d/S50dropbear`); the only change is the umask lines. dropbear writes its host keys 0600 itself, whatever the umask. Other secrets set their own modes where they are written: `/data/ad5x/ssh` 0700 (S05 at each boot), the root password copy `/run/ad5x/shadow` 0600 (written with umask 077), the update server token `/data/ad5x/kiln-os.token` 0640 root:klipper (S68), the plugin root scripts' scratch folder `/run/ad5x-plugin-root` 0700. Files that root created 0600 over SSH before this change keep their mode: nothing at boot can tell which of them the owner meant to keep private, so they are not changed (`chmod 644 FILE` by hand).
